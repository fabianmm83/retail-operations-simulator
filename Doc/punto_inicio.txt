Paso 1 — Crear el proyecto base

Abre PowerShell en:

cd "C:\Users\Fabia\OneDrive\Escritorio\retail-operations-simulator"

Y crea el entorno virtual:

py -3.12 -m venv .venv

Actívalo:

.\.venv\Scripts\Activate.ps1

Deberías ver algo parecido a:

(.venv) PS C:\Users\Fabia\OneDrive\Escritorio\retail-operations-simulator>

Después instalaremos las dependencias iniciales:

pip install fastapi uvicorn[standard] sqlalchemy psycopg[binary] alembic pydantic-settings faker numpy

Y las de desarrollo:

pip install pytest httpx ruff

Luego guardamos:

pip freeze > requirements.txt
Pero prefiero que usemos pyproject.toml

Como este proyecto queremos llevarlo a un nivel serio, no dejaría requirements.txt como nuestra configuración principal. Podemos usar pyproject.toml desde el comienzo y posteriormente hacer:

ruff
pytest
build

con una configuración centralizada.

Por eso, antes de continuar con instalaciones indiscriminadas, vamos a establecer el pyproject.toml correctamente.

La primera versión será deliberadamente pequeña:

[project]
name = "retail-operations-simulator"
version = "0.1.0"
description = "Stateful retail operations simulator for the Cuidado con Rikochet data ecosystem."
requires-python = ">=3.12,<3.13"
dependencies = [
    "fastapi",
    "uvicorn[standard]",
    "sqlalchemy",
    "psycopg[binary]",
    "alembic",
    "pydantic-settings",
    "faker",
    "numpy"
]

[project.optional-dependencies]
dev = [
    "pytest",
    "httpx",
    "ruff"
]

[tool.ruff]
line-length = 100
target-version = "py312"

[tool.pytest.ini_options]
testpaths = ["tests"]

Guárdalo como:

pyproject.toml

y entonces instala el proyecto:

pip install -e ".[dev]"

Paso 3 — Primera aplicación FastAPI

Crea:

app/main.py

con:

from fastapi import FastAPI

app = FastAPI(
    title="Cuidado con Rikochet - Retail Operations Simulator",
    version="0.1.0",
    description=(
        "Stateful retail operations simulator for the "
        "Cuidado con Rikochet data ecosystem."
    ),
)


@app.get("/health")
def health_check() -> dict[str, str]:
    return {
        "status": "ok",
        "service": "retail-operations-simulator",
    }

Ejecuta:

uvicorn app.main:app --reload

Y abre:

http://127.0.0.1:8000/health

Deberías recibir:

{
  "status": "ok",
  "service": "retail-operations-simulator"
}

También tendremos automáticamente:

http://127.0.0.1:8000/docs

para Swagger.
